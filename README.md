# price-bot —— 纯手机版比价锁单机器人

**一台安卓手机搞定全部，不需要电脑。**

监控你在淘宝/天猫和京东看中的商品，定时走到**确认订单页**读取叠加所有优惠后的真实实付款，满足「全网最低 + 近 30 天最低（或心理价位）」时自动**提交订单锁单**，Server酱推送到你微信，你手动付款。

```
你的手机（AutoX.js 常驻运行 main.js）
  ├─ config.js    商品清单 + 判定参数（唯一需要你编辑的文件）
  ├─ 定时调度      每 4 小时一轮巡检
  ├─ taobao.js    淘宝/天猫：链接直达→领券→选SKU→确认订单页取实付款
  ├─ jd.js        京东：同上
  ├─ storage.js   本地 JSON 存价格快照（历史价曲线数据源）
  ├─ judge.js     判定：全网最低 + 近30天最低 + 心理价位 + 异常价保护
  └─ Server酱推送  低价提醒 / 锁单结果 → 你的微信
```

## 部署（10 分钟）

1. **装 AutoX.js**（Auto.js 开源续作，GitHub 搜 AutoX 下载 APK），开启：无障碍服务、悬浮窗、自启动；系统设置里给它**关闭电池优化**
2. 手机设置：**锁屏密码设为“无”**（脚本会自动点亮屏幕并上滑解锁；有密码则解锁不了），**息屏时间调最短**（15~30 秒，跑完自动息屏，不用一直亮屏）
3. 在淘宝、京东 App 里登录你的账号，设置好默认收货地址
4. 把 `autojs/` 整个目录传到手机的 AutoX.js 脚本目录（`/sdcard/脚本/`）
5. 编辑 `config.js`：
   - 填 Server酱 SendKey（https://sct.ftqq.com/ 免费申请，不想推送可留空）
   - 把 `groups` 里的示例换成你的真实商品链接和 SKU 规格文字
   - `dryRun` 先保持 `true`（只比价不锁单），验证一两周再改 `false`
   - `runWindow` 设成你不用手机的时间段（主力机）或留空 `[]`（闲置机全天跑）
6. 运行 `main.js`，保持常驻

## 工作方式

- **取价（probe）**：每 4 小时对清单里每个商品，在淘宝和京东各走一遍「领券 → 选 SKU → 确认订单页」，读取实付款存本地，**不提交订单**
- **判定**：凑齐两个平台报价后判定——该平台当前全网最低，且刷新近 30 天最低（或低于你设的 `targetPrice`），才动手
- **锁单（submit）**：命中的平台重新走一遍，这次点「提交订单」，停在待付款页，推送通知你。**你不付款订单就自动取消，零成本**
- **风控保护**：遇到滑块/验证码自动暂停该平台 12 小时并推送通知；取到离谱低价（低于近期中位价 30%）判定为取数错误，不锁单

## 维护

- **脚本失灵先改 `selectors.js`**：App 大版本更新后按钮文案变了，用 AutoX.js 的「布局分析」看新文案改配置，业务逻辑不用动
- 前一两周没有历史数据，判定以 `targetPrice` 为主；历史价攒起来后自动生效
- 巡检间隔别小于 1 小时，几个商品的量保持“像真人刷 App”的节奏最安全

## 注意

- 脚本运行时屏幕会被占用，建议用闲置手机，或在你睡觉/不用手机的时间段跑
- 支付永远你手动完成，脚本不接触支付密码
- 纯自用设计，不要对外提供服务
